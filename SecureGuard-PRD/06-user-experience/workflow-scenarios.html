SGCS PRD 06 用户体验 典型工作流场景

典型工作流场景 (Workflow Scenarios)

涵盖漏洞扫描、DSAR 自动化响应与 DPIA 评估的三大标准工作流

1. 扫描引擎触发周期/增量扫描 -> 2. 漏洞关联引擎评估 PII 影响并打分 -> 3. PRE >= 85 自动在 Jira 创建 High-Priority 工单 -> 4. 工程师部署补丁或开启虚拟防护 -> 5. 系统自动复测并闭环工单。

1. 用户在合规门户提交删除申请 -> 2. DPO 在 SGCS 控制台审核通过 -> 3. 系统向包含该用户 PII 的所有数据库/S3 下发清除 API -> 4. 确认清除后自动生成审计凭证报告。
